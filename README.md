# Portafolio profesional de Derlis Aguilera

Portafolio enfocado en ecommerce, marketing digital, análisis de productos, operaciones, logística, datos y gestión ágil.

## Posicionamiento

**Ecommerce Strategy, Product & Operations Analyst**

El sitio presenta experiencia en:

- Gestión ecommerce y Shopify
- Marketing digital y medición
- Productos, catálogo, precios y stock
- Operaciones comerciales y logística
- SQL, analítica y reporting
- Scrum, Kanban y mejora continua
- Automatización e inteligencia artificial

## Tecnologías

- Next.js 15
- React 19
- TypeScript
- CSS
- Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

## Validación

```bash
npm run typecheck
npm run build
```

## Analítica

Para activar Google Analytics 4, configurar en Vercel:

```text
NEXT_PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

El sitio registra eventos para clics en WhatsApp, descarga del CV, LinkedIn y proyectos externos.
